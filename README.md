# Portfolio — Yao Tristan Max

Site d'une seule page en HTML, CSS et JavaScript, prêt pour GitHub Pages.

- `index.html` : tout le texte (projets, compétences, contact)
- `style.css` : le design (couleurs en haut du fichier)
- `script.js` : pile de projets, bande de logos, menu, animations
- `images/photo.webp` : ma photo
- `images/parcauto.webp`, `medichezvous.webp`, `suanx.webp` : captures des projets (1280 × 800)
- `images/apercu.png` : image affichée quand on partage le lien (1200 × 630). Si l'adresse du site change, modifier `og:url` et `og:image` dans `index.html`
- `images/logos/` : logos des compétences (Simple Icons, licence CC0)
- `cv/CV_Yao_Tristan_Max.pdf` : mon CV
